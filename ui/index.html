What went over the wire

ResolveHandle is a PUBLIC_FUNCTION, so it is a plain HTTP POST — no wallet, no signature, no fee, and it keeps answering even when the contract's execution fee reserve is empty. The offsets below are the real ones from tests/measure_sizes.cpp: if they ever stop matching, the decoder and the contract have drifted apart.

Reverse resolution

Address → handle. Opt-in: an owner sets it with SetPrimary, and the contract re-checks the forward record on every read — so a stale entry is inert rather than misleading.

Prototype for QHandle, a human-readable naming service for Qubic. Read-only: this page never signs or broadcasts anything. Registration uses commit–reveal — two transactions at least five ticks apart — which needs key handling and is deliberately out of scope here. Addresses appear as hex; rendering them as 60-character Qubic identities needs a K12 checksum, available from @qubic-lib/qubic-ts-library in a real build.
